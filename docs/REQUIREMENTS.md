# 01_REQUIREMENTS.md

## 📌 프로젝트 개요
트로트 가수 팬카페 플랫폼 백엔드 설계 및 개발.  
팬들이 게시글을 작성하고 소통하며, 굿즈 정보와 일정을 확인할 수 있는 커뮤니티 시스템을 제공한다.

## 🎯 주요 목표
- MVP 단계에서는 회원가입/로그인, 게시판(이미지 포함), 댓글, 좋아요, 굿즈 정보 조회, 일정 기능을 포함
- 향후 관리자 기능 및 알림 시스템, 팬카페 멀티화(SaaS 구조)로 확장 가능

---

## 👤 사용자 시나리오 (User Flow)

### [일반 사용자]
1. 이메일로 회원가입 및 로그인
2. 홈 피드에서 게시글 목록 조회
3. 게시글 작성 (텍스트 + 이미지)
4. 게시글에 댓글/대댓글 작성
5. 게시글 좋아요
6. 굿즈 목록과 프로모션 확인
7. 일정(캘린더) 확인

### [운영자 (admin)]
1. 공지사항 작성 (is_notice = true)
2. 일정 등록 및 수정
3. 게시글/댓글 삭제 권한
4. (*차후*) 알림 발송, 회원 관리 등

## ✅ 기능 요구사항 목록

| 기능 영역 | 기능 | 설명 |
|-----------|------|------|
| 회원 | 회원가입 / 로그인 | JWT 기반 인증, 비밀번호 암호화 저장 |
| 게시판 | 게시글 CRUD | 이미지 업로드 포함 |
| 댓글 | 댓글 / 대댓글 | 계층형 구조 |
| 좋아요 | 좋아요 토글 | 유저-게시글 연결 테이블 사용 |
| 굿즈 | 상품, 프로모션 조회 | 관리자에 의해 미리 등록된 정보 |
| 일정 | 월별 일정 조회 | 관리자 등록 |
| 관리자 | 공지 작성, 게시글 삭제 | 운영자 role 권한 확인 후 가능 |

---

## 🛠 비기능 요구사항

- 인증 방식: JWT + Refresh Token
- 이미지 저장: AWS S3 또는 Firebase Storage
- DB: MySQL (InnoDB), UTF8MB4
- 에러 처리: 공통 예외 핸들러 적용
- 삭제 정책: Soft Delete (`deleted_at`)
- 운영자 인증: Role 기반 인가
